Local-first personal OS

The one place you steer your working life from.

SigmaHelix is a personal operating system that runs on your own machine — tasks, notes, projects, calendar, launchers, and an assistant that watches your other projects and helps you act on them. Nothing is sent to the cloud unless you turn a cloud model on, and the key stays in your OS keyring.

Released 1.0.0. The durable core, the desktop app, the web UI and the CLI are complete and tested — 385 automated tests pass and the code is 72% covered, with the full gate green in CI on every push.

What it is

SigmaHelix is the Hub: one surface that scans the projects on your machine, scores their health, and lets an assistant (Tommy) read, assess and build inside them — while keeping an append-only, hash-proven record of everything that happened, so nothing is invisible.

What you can do

Tasks

A task is a question seeking an answer; it is only done once every sub-question is answered with evidence.

Projects

Auto-discovers your other repositories, scores their health, and gives each a Run link.

Assistant

Tommy runs locally first, shows its thinking and token usage, and writes real results instead of refusing.

Audit & backup

Every mutation is recorded in an append-only SHA-256 hash chain, with verifiable backups.

Private and safe

There is no account, no sync service, and no telemetry. Cloud models are off by default; when enabled, the API key lives in your OS keyring and is never written to a file. The web UI serves on loopback only and every call needs a per-session token, so no other process on your machine can drive it.

Honest boundary

This is a personal, founder-only tool. It has not had an external security audit, there is no hosted multi-user deployment, and no revenue has been realised. It is built to be inspected, not to be a product you buy.
