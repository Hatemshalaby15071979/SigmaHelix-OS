# SigmaHelix glossary

| Term | Meaning |
|---|---|
| Approval | A time-bounded human decision bound to the hash of one proposed action payload. |
| Domain event | A named fact that has occurred, with its occurrence time and JSON data. |
| Evidence | A source-backed claim, optionally linked to a project and an artifact hash. |
| Note | User-authored durable text, optionally associated with a project. |
| Project | A named local project directory registered in SigmaHelix. |
| Task | A durable unit of work. For recurring tasks, each scheduled occurrence has its own completion state. |
| Tenant scope | The data-isolation key carried by each record. v1 uses the local single-user scope `local`; it does not imply multi-tenant support. |
